# Real Estate Iraq — Screen Map

Bottom navigation: **Home · Explore · Add (+) · Favorites · Profile**. Default locale ckb (RTL). Light/dark themes.

## Onboarding & auth
1. Splash / locale picker (first run: کوردی · العربية · English)
2. Phone entry (+964 prefix, Iraqi mobile validation 7XX XXX XXXX)
3. OTP (6 digits, resend timer)
4. Account type picker (Individual / Owner / Agent / Company / Developer)
5. Profile setup (name, photo, governorate, district)

## Home
Search bar → assistant · governorate chips · featured carousel · new listings · categories grid · companies strip · banners.

## Explore
List/Map toggle · filter sheet (all filters in search spec) · sort · save search · map clustering, "search this area" · AI assistant entry.

## Property details
Gallery (photos/videos, before/after badges) · price, negotiable · specs (category-specific) · description · map · owner/company card with verification badges (Phone / Identity / Company / Documents reviewed — separate) · similar · actions: Call, WhatsApp, Message, Save, Share, Report, Compare.

## Add property (wizard)
1 Category & transaction type → 2 Location (governorate→district→neighborhood + map pin) → 3 Details (dynamic per category) → 4 Photos & videos (up to 20, reorder, cover, AI enhance) → 5 Price & contact → 6 Review → **7 Payment** (only if fee required: service, 30,000 IQD, FIB / Qi Card, reference) → 8 Payment status (processing / success / failure+retry) → 9 Submitted for approval.

## My listings
Tabs by status (Drafts, Awaiting payment, In review, Published, Rejected (reason), Expired/Archived) · actions per state · stats (views, favorites, leads).

## AI Studio
Image enhancer (before/after) · virtual staging (labeled) · AI Video Maker: select photos → style, duration (15/30/60), format (9:16/16:9/1:1), music, transitions, overlays → price screen (30,000 IQD) → payment → progress → preview / regenerate / download / share / save to gallery.

## Favorites
Folders · compare (≤4 side-by-side) · recently viewed.

## Messages
Conversation list (unread badges) · chat (images, read receipts, block, report).

## Profile
Edit profile · verification center · my payments (receipts by reference) · company dashboard (members, assignment, leads, analytics) · notifications · language · theme · help · delete account.

## Admin (web)
Overview KPIs · users · properties moderation queue · categories & locations · payments (filters: date/user/service/provider/status/amount) · refunds · prices · providers · AI management & costs · settings · audit logs.

Every screen ships with loading, empty, error and offline states.
